02 · Main flow

감지부터 복귀까지

한 번의 모듈 동작으로 끝내지 않고, 서버의 최신 센서 판정과 로봇 보고를 계속 주고받으면서 다음 행동을 결정합니다.

상시 센싱

ZONE2·ZONE99 노드가 자동차 상태와 관계없이 온·습도를 계속 서버로 보냅니다.

DHT → ESP-01 → /api/readings

이상 판정

서버가 온도·습도와 45초 데이터 신선도를 확인합니다. 습도 위반 해제에는 2% hysteresis를 적용하고, 이상 후보가 없더라도 센서가 stale이면 ALL_STOP입니다.

NORMAL · ERROR_LOW · ERROR_HIGH · STALE

목표 선정

동시 위반이면 임계값 초과 폭과 지속시간으로 우선순위를 계산해 하나의 TASK와 revision을 만듭니다.

target_zone + action + revision

프로토콜·HOME 동기화

부팅 경로는 UNKNOWN입니다. 4모터 PROTOCOL_SYNC exact ACK 뒤 HOME 마커에서 ZONE2 방향으로 놓고 CALIBRATE_HOME을 완료하기 전에는 이동하지 않습니다.

SYNC=7 / STATUS=8 → HOME=6 / STATUS=7

출동 준비

SensorUno가 RC522 VersionReg, I2C 적용 ACK와 경로 방향을 검사한 뒤 출발합니다. N20 쪽 후방 초음파는 전진을 차단하지 않습니다.

RFID health → Motor frame

연속 라인 추종

MotorUno는 IR 센서로 끊기지 않은 검은 선을 계속 따라갑니다. SensorUno는 주행 중 RFID 스캔·I2C ACK·keepalive를 우선 처리합니다.

LINE FOLLOW + RFID SCAN · 400ms KEEPALIVE

RFID 감지·정지

예상 역의 UID가 읽히면 SensorUno가 즉시 모터를 정지합니다. 중간 역이면 해당 UID를 중복 억제 상태로 두고 다시 출발하며, 목표 역이면 정차를 유지합니다.

RC522 UID → MOTOR STOP → STATION CONFIRM

모듈 작동

4바이트 sequence+CRC 명령을 보내고 같은 sequence의 RUNNING을 확인합니다. 가습 5초 또는 팬 0.5초→펠티어 5초→팬 2초 뒤 같은 tuple의 DONE만 인정합니다.

4B CONTROL ⇄ 6B EXACT ACK

재판정

모듈 완료 시 서버가 그 구역의 마지막 reading ID를 DB에 소비 처리하고 출력 OFF로 대기합니다. 그 이후 수신된 새 측정도 비정상일 때만 새 revision으로 한 번 더 작동하며, 정상화되면 RETURN_HOME을 만듭니다.

DB reading watermark · 새 측정 1건 = 다음 동작 1회

복귀·재라우팅

HOME으로 복귀할 때는 차체를 돌리지 않고 후진합니다. 이동 방향 반대편에 새 TASK가 생기면 잠시 전체 RELEASE 후 전진·후진 방향만 바꿉니다.

RETURNING 상태에서도 서버 감지 지속

대기 복귀

HOME 도착 후 IDLE로 전환하고 9초 HEARTBEAT만 유지합니다. 다음 위반을 기다립니다.

IDLE · outputs OFF · online 유지
03 · Route model

직선 3지점 경로

데모 트랙은 HOME, ZONE2, ZONE99가 직선으로 놓입니다. ZONE2·ZONE99 구간의 검은 선은 끊기지 않고 바닥 RFID로 역을 구분하며, HOME에만 양쪽 IR이 동시에 읽는 넓은 검은 종점 마커를 둡니다.

0
HOME넓은 검은 종점 마커
1
ZONE2연속 선 위 RFID
2
ZONE99연속 선 위 RFID
HOME → ZONE99연속 검은 선을 추종하며 ZONE2 카드를 주행 중 읽습니다. 잠시 멈춰 중간 역을 기록한 뒤 같은 방향으로 재출발하고, ZONE99 카드에서 정지해 임무를 시작합니다.
ZONE99 → HOME차체 자세를 유지한 채 네 바퀴를 후진시켜 같은 검은 선을 따라갑니다. ZONE2 카드를 중간 지점으로 확인한 다음, 양쪽 IR이 HOME의 넓은 검은 종점 마커를 읽으면 정지합니다.
복귀 중 TASK현재 이동 방향 앞쪽 목표면 그대로 진행하고, 반대편 목표면 120ms 전체 RELEASE 후 네 바퀴의 전진·후진 방향을 바꿔 재라우팅합니다.

역 확인 규칙

route safety
RFID가 구역을 확정

라인센서는 조향에만 사용합니다. RC522가 등록 UID를 읽었을 때만 ZONE2 또는 ZONE99 도착으로 확정합니다.

주행 중 반복 스캔

MOVING·RETURNING에서도 짧은 주기로 카드를 검사합니다. 예상 UID가 감지되면 정지 명령을 우선 전송합니다.

중간 역은 재출발

목표가 아닌 예상 역이면 잠시 정지해 위치를 갱신하고 같은 전진·후진 방향으로 다시 출발합니다. 방향이 바뀐 직후에는 방금 처리한 카드가 안테나 범위에서 벗어난 것을 확인한 다음 RFID 판정을 재개합니다.

HOME만 검은 종점 마커

정상 복귀는 HOME 방향으로 ZONE2 RFID를 확인한 뒤 만나는 양쪽 IR 동시 검정에서 완료됩니다. ZONE2 태그를 놓쳐도 마커에서 정지해 HOME 위치는 복구하지만, 성공으로 처리하지 않고 FAILED / HOME_RFID_MISSED를 보고합니다. 향후 HOME RFID를 추가하면 위치 확인을 더 명확하게 만들 수 있습니다.

재부팅 후 버전·HOME 동기화

MotorUno는 부팅 상태 8에서 command 7 exact ACK로 4모터 의미를 확인한 뒤 상태 7로 이동합니다. 차량을 HOME에서 ZONE2 방향으로 놓고 명령 6·상태 0을 확인해야 AUTO로 복귀합니다. 구형/부분 업로드는 주행을 열지 않습니다.

04 · State machine

자동차 상태 전이

서버 명령, 주행 중 RFID, 모듈 DONE과 구역 습도 정상 판정을 단계별 조건으로 사용합니다. 오류 시 정상 순서를 건너뛰고 안전 정지 상태로 이동합니다.

PROTOCOL / CALIBRATION REQUIRED

대기·출발 잠금

부팅 직후 UNKNOWN·status 8·출력 OFF. v2 sync 뒤 status 7, HOME calibration 뒤에만 IDLE에서 이동.

MOVING

출동 이동

MotorUno 전진, RFID와 I2C 상태, keepalive를 계속 감시. 후방 초음파는 전진 중 측정만 합니다.

RFID_STOP · 목표

역 확인·정지

주행 중 읽은 RC522 UID와 expected station을 비교하고 MotorUno STOP을 확인.

MODULE_RUNNING

환경 제어

가습 또는 제습 동작. RUNNING 이후 같은 명령의 DONE만 인정.

TASK_COMPLETE

결과 보고

서버에 COMPLETED/FAILED와 이벤트를 전송하고 다음 명령 대기.

RETURNING

복귀

HOME 방향 이동. 새 임무가 오면 현재 위치·방향으로 재라우팅.

REAR ULTRASONIC

전진은 관측만 합니다. 후진 출발 전 stale·STUCK_HIGH·15cm 미만 값은 출발을 거절하고, 주행 중 위험은 PAUSE합니다.

COMMUNICATION FAULT

I2C ACK, sequence, Wi-Fi 또는 서버 연결 실패 시 모터·액추에이터를 정지하고 FAILED 보고.

ROUTE DESYNC

예상하지 않은 등록 RFID, RFID 이후 잘못된 재출발 또는 주행 timeout은 임무 중단.

SYNC REQUIRED

부팅·Motor 재부팅 뒤 status 8의 프로토콜 ACK와 status 7의 HOME 보정을 모두 다시 완료해야 합니다.

06 · Command contract

서버 명령과 통신 계약

수동 명령은 자동 임무를 일시적으로 덮어쓰며, 같은 revision의 ACK가 오기 전에는 다음 수동 명령을 막습니다. ALL_STOP만 안전상 예외입니다. CALIBRATE_HOME은 AUTO 전환이나 구역 TASK와 구분되는 재부팅 안전 동기화 명령입니다.

SensorUno가 처리하는 명령

server → robot
TASK

target_zone과 HUMIDIFY/DEHUMIDIFY를 받아 경로 임무 시작

CALIBRATE_HOME

PROTOCOL_SYNC=7/status 8로 4모터 세대를 확인하고 두 출력 보드를 정지한 뒤 HOME_SYNC=6/status 0을 확인합니다. 실제 HOME·ZONE2 방향 배치는 사용자가 확인합니다.

RETURN_HOME

현재 위치에서 HOME 경로 시작, 이미 HOME이면 즉시 완료

ALL_STOP

모터와 모든 액추에이터를 즉시 OFF하고 IDLE 전환

MOTOR_FWD

M1~M4 전진 수동 라인 주행. 경로 위치를 UNKNOWN으로 만들므로 이후 HOME 재보정 필요

MOTOR_RETURN

보정된 위치·RFID 경로를 사용해 차체를 돌리지 않고 HOME까지 후진; 임의 벤치 역회전이 아님

MOTOR_STOP

MotorUno 정지와 로봇 상태 정리

ACT_HUMIDIFY

ActuatorUno 가습 릴레이 단위 시험

ACT_DEHUMID

팬 선가동·펠티어·팬 후열 냉각 순서 시험

ACT_STOP

ActuatorUno 전체 출력 OFF

RFID_TEST / I2C_CHECK

RFID placeholder 및 두 slave 연결 상태 진단

07 · Safety

실차 안전 로직

서버가 느리거나 통신이 끊겨도 각 보드가 로컬에서 출력을 끌 수 있도록 계층별 방어를 둡니다.

US

후진 출발·장애물 보조 정지

최신 sample이 없거나 STUCK_HIGH·15cm 미만이면 후진 출발을 거절합니다. 주행 중 같은 위험은 PAUSE하고 18cm 이상 3회 뒤 RESUME합니다.

E!

ECHO 오류 구분

STUCK_HIGH는 후진을 멈추지만 NO_ECHO·OUT_OF_RANGE는 넓은 공간일 수 있어 진단만 남깁니다. 이미 PAUSE 상태이면 다시 유효한 clear 3회 전에는 재개하지 않습니다.

2s

Motor watchdog

SensorUno 명령 또는 KEEPALIVE가 2초간 없으면 MotorUno가 자체적으로 모든 모터를 RELEASE합니다.

RF

RFID 순서 검증

현재 expected station과 다른 등록 UID는 경로 불일치로 처리해 주행과 모듈을 멈춥니다.

I²C

적용 ACK·timeout

주소 ACK만 믿지 않습니다. Motor는 2B/3B sequence echo, Actuator는 4B/6B command+sequence+CRC를 확인하며 Wire timeout이면 전체 출력 OFF로 복구합니다.

LCD

표시 오류 격리

D5/D4 LCD의 무응답·버스 고착·쓰기 실패는 표시 오류와 0x27→0x3F 재탐색으로 처리합니다. A4/A5의 릴레이 상태 머신과 안전 OFF는 독립적으로 유지합니다.

TAG

RFID 정지 우선

등록 UID 감지 시 주행 명령보다 STOP을 우선하고 적용 ACK를 확인합니다. 태그가 사라지기 전에는 같은 역을 중복 처리하지 않습니다.

HM

HOME 마커 조건

복귀 방향에서 ZONE2 RFID까지 확인한 뒤의 양쪽 IR 동시 검정만 정상 완료입니다. 중간 태그가 누락된 경우에도 마커에서 정지하고 위치를 HOME으로 복구하되, 누락 실패를 보고해 재점검하게 합니다.

CAL

재부팅 출발 인터록

재부팅 뒤 route=UNKNOWN·Motor status=8에서 이동을 막습니다. PROTOCOL_SYNC exact ACK로 status 7에 진입한 뒤, HOME 배치와 CALIBRATE_HOME 완료 ACK가 있어야 해제합니다. IR은 차체 방향을 판별하지 못하므로 ZONE2 방향은 사용자가 확인합니다.

5s

액추에이터 자동 OFF

가습 5초, 제습은 팬 0.5초 선가동·펠티어 5초·팬 2초 후열 냉각입니다. 부팅·STOP·I2C 오류는 모두 OFF입니다.

NET

서버 단절 대응

진행 중 서버 연결이 끊기면 모터·액추에이터를 정지하고 복구 후 FAILED 이벤트를 보고합니다.

09 · Safe test order

다음 통합 시험 순서

고전력 모듈과 모터는 마지막에 연결합니다. 각 단계의 OFF와 ACK가 확인돼야 다음 단계로 넘어갑니다.

STEP 01전원·ESP 연결 확인

배선과 3.3V 전원을 확인한 뒤 ESP-01을 재인가하고 AT·Wi-Fi 응답을 기록.

STEP 02동일 릴리스·안전 부팅

Sensor/Motor/Actuator를 같은 커밋으로 업로드하고 Motor status 8, 모든 출력 OFF와 PROTOCOL_SYNC command 7 exact ACK를 확인합니다.

STEP 03HOME 기준 동기화

차량을 HOME 마커 위에서 ZONE2 방향으로 놓고 CALIBRATE_HOME → status 7을 거쳐 status 0/command 6 exact ACK를 확인합니다.

STEP 04바퀴 공중·트랙 시험

M1~M4 개별 방향, M1+M3/M2+M4 쌍, 전체 전진·후진, 축별 PWM 정합, 연속선 보정, RFID 중간 역과 HOME 정지를 확인합니다. 후방 초음파는 후진 장애물 PAUSE만 시험합니다.

STEP 05릴레이 무부하 시험

4B/6B exact ACK와 함께 LED·멀티미터로 A0 5초, D7 선가동→A1 5초→D7 후열 2초를 확인.

STEP 06전체 경로 시험

HOME→ZONE2→ZONE99→HOME, 중간 역과 복귀 중 새 TASK를 순서대로 검증.

이 문서는 현재 설계와 검증 경계를 설명합니다. 환경별 주소·포트·태그 UID·자격 증명은 포함하지 않습니다.
