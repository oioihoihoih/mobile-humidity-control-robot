# 4륜 이동형 제습·가습 로봇 SimulIDE 데모

> **레거시:** 이 문서는 초기 단일 Uno와 `ZONE1 + ZONE2` 회로 기록입니다. 현재 3 Uno와 `ZONE2 + ZONE99` 시뮬레이션은 [THREE_UNO_PROXY.md](THREE_UNO_PROXY.md)를 사용합니다.

시뮬레이션 파일은 `mobile_humidity_robot_4wd_full_system.sim2`입니다. 기존의 간단한 LED 파일은 보존했고, 이 파일은 **DC 모터 4개가 실제 회전**하는 4륜 차체 데모입니다.

> 이 레거시 회로에서는 Uno와 4개 모터 사이에 L298N 기능을 등가화한 듀얼 H-브리지가 들어갑니다. Uno D3~D6은 MOSFET의 게이트 제어만 하고, 모터 전류는 별도의 5V 모터 레일에서 나옵니다. 자세한 배선과 실물 L298N 치환표는 [L298N 등가 회로 문서](L298N_EQUIVALENT_DRIVER.md)를 참고하세요.

## 바로 실행하기

1. `firmware/uno_full_robot_demo/uno_full_robot_demo.ino`를 Arduino Uno용으로 컴파일한다.
2. 생성된 `uno_full_robot_demo.ino.hex`가 같은 폴더에 있는지 확인한다.
3. SimulIDE에서 `mobile_humidity_robot_4wd_full_system.sim2`를 연 뒤, 전원 버튼을 누른다.
4. 시작 약 2.5초 후 Zone 1(72% RH)이 Zone 2(35% RH)보다 심각하므로 로봇은 Zone 1을 목표로 판단하고, 앞·뒤 좌·우의 4개 모터가 회전한다.
5. `RFID proxy: ZONE1` 버튼(또는 키 `1`)을 누르면 Zone 1 도착으로 처리된다. 제습 릴레이 표시와 방열팬 모터가 켜진다.
6. DHT22의 `Humi` 속성을 40~60%로 바꾼 뒤 `RFID proxy: HOME`(키 `h`)을 누르면 복귀 상태를 확인할 수 있다. 이동 중에 다른 구역 습도를 다시 범위 밖으로 바꾸면 우선순위가 다시 계산된다.

`IR line` 버튼은 키 `l`(좌), `c`(중앙), `r`(우)로도 눌러 라인 보정을 확인한다. 평소에는 중앙 라인을 따라가는 것으로 가정해 버튼을 누르지 않아도 직진합니다. HC-SR04의 거리 입력은 1 m로 고정돼 있어 정상 주행합니다. `obstacle distance`의 전압을 0.14 V 이하로 바꾸면 15 cm 미만 장애물로 판정되어 모터가 멈추고 부저가 울립니다.

## 시뮬레이션과 실물의 대응

| 실제 구성품 | 이 `.sim2`에서의 표현 | 실물 제작 시 주의 |
| --- | --- | --- |
| 4WD 샤시 + DC 모터 4개 | 실제 `DcMotor` 4개. 좌 2개와 우 2개가 각 방향 신호를 공유 | 왼쪽·오른쪽 모터 극성은 장착 방향에 맞게 한쪽을 반대로 연결 |
| L298N 모터드라이버 | Uno 출력과 모터 사이의 **H-브리지 출력 대체 모델** | Uno 핀을 모터에 직접 연결하면 안 됨. 모터 4개의 기동전류에는 TB6612FNG 2개 또는 고전류 듀얼 드라이버 권장 |
| DHT22 + ESP32 2개 + 서버 | DHT22 2개를 Uno에 직접 연결하고, Uno 내부 스케줄러가 서버 우선순위 역할을 수행 | 실제에는 ESP32 2개가 Wi-Fi로 서버에 전송하고, 서버가 로봇 ESP32로 명령 전송 |
| 3채널 IR 라인트레이싱 센서 | `Push` 3개(라인 감지 시 LOW) | 실제 IR 모듈의 DO 3개를 로봇 제어 보드에 연결 |
| RFID 리더/태그 3지점 | `Push` 3개(도착 태그 감지) | 실제에는 MFRC522 등 리더로 HOME/ZONE1/ZONE2 UID를 판별 |
| HC-SR04 | 실제 `SR04` 컴포넌트 | 실물에서는 5V Echo를 ESP32에 연결할 때 분압 필요 |
| 릴레이 2채널 + 가습 진동자 | 파란 릴레이 출력 LED | 초음파 가습기는 물탱크·진동자 드라이버 전원을 릴레이/MOSFET으로 스위칭 |
| TEC1-12706 + 방열판 + 팬 + 응결수 트레이 | 노란 릴레이 출력 LED + 실제 회전하는 방열팬 모터 | TEC1-12706은 약 12V·6A급. IRF520과 Uno/ESP32 GPIO만으로 직접 구동하지 말고, 로직레벨 MOSFET·퓨즈·충분한 방열·분리 전원을 사용 |
| 부저 | `AudioOut`의 buzzer 모드 | 실물 피에조 부저를 D13(또는 ESP32 지정 GPIO)에 연결 |
| Li-Po 11.1V + DC-DC | 전기적 부하 대신 논리 모델로만 반영 | 실물은 12V 고전력 레일(TEC/모터)과 5V/3.3V 로직 레일을 DC-DC로 분리하고 GND만 공통화 |
| OLED I2C | 시리얼 로그 화면으로 대체 | 실물에서는 상태·목표구역·습도를 OLED에 표시 |
| 물탱크·급수관·응결수 트레이·트랙 | 기구물이라 회로 시뮬레이션 대상 밖 | 시연물에 실제 장착, 누수 방지와 무게 중심 확인 |

## 검증 범위

이 파일은 SimulIDE에서 지원되는 Arduino Uno, DHT22, HC-SR04, 푸시버튼, 부저, LED, DC 모터만 사용하여 열립니다. 펠티어·초음파 진동자·L298N·ESP32 Wi-Fi·RFID는 해당 SimulIDE 배포판의 직접 모델이 없어, 위 표의 실행 가능한 대체 모델로 표현했습니다. 따라서 로봇의 핵심 제어 흐름(습도 우선순위 → 4륜 이동 → 도착 → 가습/제습 → 복귀 중 재판정)을 회로상에서 검증할 수 있습니다.
